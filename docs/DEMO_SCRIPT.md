# NutriVibe — 90-second demo script (Phase 8)

Use this for a Loom / phone screen recording for your portfolio.

## Setup before recording

1. Open the **live** site (or local with both servers running).  
2. Be logged in with a profile that has **Dairy** allergy.  
3. Have barcodes ready: `4567890123456` (yogurt) and optionally a plant-milk product.

## Script

1. **Home (5s)**  
   “NutriVibe gives a personalized food safety verdict from a barcode or label scan — based on *your* allergies, diet, and meds.”

2. **Profiles (10s)**  
   Show “Scanning for: Me” / a dependent. “Families can track more than one person under one account.”

3. **Scanner (25s)**  
   Enter barcode `4567890123456` → show loading → product page.  
   Point at **Unsafe** (or Caution) badge: “Greek yogurt is flagged because of dairy.”

4. **AI explain (15s)**  
   Click explain if available: “Gemini explains ingredients in plain English — not medical advice.”

5. **Dashboard (20s)**  
   Show Safe/Caution/Unsafe counts, search, Export CSV.  
   “You can review the day and export a log.”

6. **Close (10s)**  
   “Stack is React, Node, MongoDB, Open Food Facts, and a single shared safety engine. Code is on GitHub.”

## Tips

- Speak slowly; zoom browser to 110–125%.  
- Avoid showing `.env` or real passwords.  
- 60–120 seconds is ideal for recruiters.
